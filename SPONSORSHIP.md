# Sponsorship

httpjet is free software. Sponsorship is a voluntary way to fund maintenance;
it is not a software license purchase and does not change anyone's GPL rights.

## Recognition-only tiers

When the GitHub Sponsors profile is active, the intended monthly tiers are:

- **Supporter — $5:** optional name or handle in periodic acknowledgements.
- **Sustainer — $25:** the same recognition, grouped as a Sustainer.
- **Backer — $100:** the same recognition, grouped as a Backer.
- **Custom:** recognition in the nearest tier when requested.

Every tier receives the same public source, releases, issue tracker, and
security fixes. Sponsorship does not include private features, a support SLA,
roadmap control, priority vulnerability disclosure, or a guarantee that a
particular change will be accepted.

Recognition is opt-in. Sponsors may remain anonymous, and acknowledgements
will not publish contact or payment details. Acknowledgement wording does not
imply product endorsement in either direction.

GitHub currently has no active Sponsors listing for the maintainer account.
After enrollment and payout verification are completed by the account owner,
maintainers will add `.github/FUNDING.yml` and enable the repository's Sponsor
button. Do not send funds to an address posted outside the verified project
and maintainer profiles.

Sponsorship may have tax consequences and should not be assumed to be a
tax-deductible charitable donation.
